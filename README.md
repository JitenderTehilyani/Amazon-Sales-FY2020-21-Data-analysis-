# Amazon-Sales-FY2020-21-Data-analysis-
This Data Analytics project analyzes Amazon sales data for FY 2020–21 using Tableau. The dashboard provides insights into revenue trends, regional performance, product category sales, and payment method distribution.

    <h1>📊 Amazon Sales Analysis Dashboard (FY 2020-21)</h1>

    <p>
        This project presents an interactive Tableau dashboard built to analyze Amazon Sales data
        for FY 2020-21. The dashboard provides insights into sales performance across regions,
        product categories, monthly revenue trends, and customer payment preferences.
    </p>

    <hr>

    <h2>🎯 Project Objective</h2>
    <p>
        The objective of this project is to analyze Amazon sales data and identify key business
        trends that can help improve decision-making, revenue growth, and customer understanding.
    </p>

    <h2>🛠️ Tools & Technologies Used</h2>
    <ul>
        <li>Tableau</li>

        <li>Business Analytics</li>
    </ul>

    <h2>📌 Dashboard Features</h2>
    <ul>
        <li>Region-wise Revenue Analysis</li>
        <li>Category-wise Revenue Analysis</li>
        <li>Month-wise Revenue Trend Analysis</li>
        <li>Payment Method Distribution</li>
        <li>Interactive Filters and Visualizations</li>
        <li>KPI Tracking and Business Insights</li>
    </ul>

    <h2>📈 Key Insights</h2>
    <ul>
        <li>South region generated the highest revenue among all regions.</li>
        <li>Mobile and Electronics categories contributed the largest share of revenue.</li>
        <li>Sales revenue showed significant growth towards the end of the year.</li>
        <li>December recorded the highest monthly revenue.</li>
        <li>Easypay Voucher was one of the most used payment methods.</li>
    </ul>

    <h2>📊 Dashboard Components</h2>
    <ul>

        <li>Category Wise Revenue Chart</li>
        <li>Month Wise Revenue Trend Line</li>
        <li>Payment Method Distribution Pie Chart</li>
        <li>State-wise Revenue Treemap</li>
    </ul>
